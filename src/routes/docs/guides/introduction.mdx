# Introduction

Welcome to the TASBox documentation!

- Use the sidebar on the left of this page to navigate guides and API documentation.
- Search documentation by the name of the name of the page, the group it's in (e.g. `Physics`) or for API docs by the
  type as well (e.g. `function`).
- The icons next to each page indicate the type of the documentation:
  - <Icon name="class"/> Class
  - <Icon name="constant"/> Constant
  - <Icon name="documentation"/> General docs (like this)
  - <Icon name="enum"/> Enum
  - <Icon name="event"/> Event
